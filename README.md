# AIエージェントの理論と実践 ハンズオン

架空の学食「ひかり食堂」を題材に、AI エージェントの仕組みを手を動かして確かめるハンズオンです。Databricks Free Edition で動作します。

## 準備

1. [Databricks Free Edition](https://docs.databricks.com/aws/ja/getting-started/free-edition) にログインする
2. ワークスペース → 作成 → Git フォルダ を開き、このリポジトリの URL を貼り付けてクローンする

データの準備は各ノートブックの中で自動的に行います（数秒で終わります）。

## ノートブック

| ノートブック | 内容 |
|---|---|
| `00_config` | 共通の設定と、メニュー表の作成。ほかのノートブックが読み込むので、直接実行する必要はありません |
| `01_llm_alone` | LLM だけに聞く → 必要な情報を貼り付けてから聞く |
| `02_react_by_hand` | LLM が依頼したツールを自分で実行して、ループを手で回す。最後にループをプログラムにする |
| `03_build_agent` | ツールを Unity Catalog に登録し、エージェントを作る。トレースを見る。ツールの名前と説明を変えて、選ばれ方の違いを見る |
| `04_evaluate_improve` | 評価データと LLM ジャッジで採点し、1か所直して、もう一度採点して比べる |

`01` から順に実行してください。`02` は「すべてを実行」を使わず、1セルずつ実行します。

## 補足

- メニュー表は演習用の架空のデータです
- LLM は `databricks-qwen3-next-80b-a3b-instruct` を使います（`00_config` で変更できます）
- データと関数は `workspace.agent_handson` に作成します
